# Workflow — Shot Design

For each shot:

1. State the shot purpose.
2. Confirm adjacent shot context.
3. Define start state.
4. Define one primary action.
5. Define performance constraints.
6. Define camera intent.
7. Define exact camera specification.
8. Define motion layers.
9. Define lighting.
10. Define sound cue if relevant.
11. Define end state.
12. Score generative complexity.
13. Check continuity.
14. Simplify if high risk.
15. Mark READY or NOT READY.
