# Workflow — Professional Color Grade

## Phase A — Intake
1. inspect source
2. verify color space / gamma
3. identify baked transforms
4. identify target deliverables
5. choose color-management strategy
6. validate monitoring

## Phase B — Technical normalization
7. RAW settings where applicable
8. input transform
9. denoise / technical cleanup if required
10. establish working space

## Phase C — Balance
11. exposure
12. white balance
13. tint
14. black / white placement

## Phase D — Matching
15. match angles
16. match scenes
17. match skin
18. match time-of-day / practicals

## Phase E — Look
19. contrast design
20. palette / hue relationships
21. saturation mapping
22. highlight / shadow color
23. texture

## Phase F — Secondaries
24. skin
25. product / brand
26. wardrobe
27. sky / windows
28. background control

## Phase G — Temporal review
29. playback in motion
30. identify flicker / pumping
31. repair tracked / temporal problems

## Phase H — Output
32. output rendering
33. HDR/SDR trim
34. graphics check
35. subtitles check
36. compressed-delivery check

## Phase I — Approval
37. scopes
38. calibrated reference review
39. consumer-device sanity review
40. final QC
