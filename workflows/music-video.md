# Workflow — Music Video

1. understand song structure
2. mark timecode sections
3. identify lyrical themes
4. map energy curve
5. choose narrative / performance / abstract balance
6. create visual motif
7. assign visual progression to song sections
8. define beat-sync rules
9. define recurring character/world states
10. build shot sequence
11. reserve complex camera for musical moments that justify it
12. validate edit rhythm against audio before generation
