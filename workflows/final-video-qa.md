# Workflow — Final Video QA

1. Load the actual assembled/master-candidate.
2. Review whole video natively when supported.
3. Record reviewer/model, audio availability, and scope.
4. Produce timecoded observed findings.
5. Run deterministic technical inspection where available.
6. Produce measured findings.
7. Cross-validate; mark causal explanations inferred unless proven.
8. Reject unsupported technical claims.
9. Assign severity and repair route.
10. Persist via `schemas/video-qa-report.schema.json` when project state is maintained.
11. Run `evals/publish-readiness.md`.
