# Workflow — Prompt Compilation

Prompt compilation happens only after shot decisions are stable.

Compile in this order:

1. canonical subject / identity
2. environment
3. initial state
4. primary action
5. performance detail
6. blocking
7. camera
8. motion
9. lighting
10. atmosphere
11. temporal behavior
12. continuity anchors
13. relevant constraints

Then adapt syntax and length to the target video model.

Do not add stylistic adjectives that contradict the approved visual bible.
Do not invent actions that are absent from the shot spec.
