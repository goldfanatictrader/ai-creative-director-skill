# Workflow — Film Development

1. brief
2. creative intent
3. logline
4. premise
5. character objective
6. conflict
7. emotional arc
8. beat sheet
9. scene list
10. screenplay or treatment
11. world / character bible
12. scene-state initialization
13. blocking
14. shot design
15. cinematography strategy
16. storyboard
17. animatic
18. canonical asset approval / locks
19. sequence state map + continuity bridges
20. sequence preflight
21. feasibility
22. generation strategy
23. generation specs
24. generation
25. output critique / repair / shot approval
26. sequence assembly
27. native final-video QA + deterministic technical QA
28. continuity + gap/redundancy/drift review
29. assembly edit
30. picture lock
31. VFX / cleanup / compositing
32. color
33. sound post / music / final mix
34. motion graphics / titles / captions
35. mastering / delivery versions
36. final-video QA on master candidate
37. publish-readiness audit
38. final approval

For concept-only or preproduction requests, stop at the requested stage. The post-production continuation applies when the user asks for a finished/publish-ready result.
