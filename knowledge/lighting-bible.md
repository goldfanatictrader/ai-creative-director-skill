# Lighting Bible

## Define light through
- source
- motivation
- direction
- size
- hardness
- intensity
- falloff
- color temperature
- contrast
- atmospheric interaction

## Sources
- sun
- sky
- window
- practical lamp
- fluorescent
- LED
- signage
- fire
- vehicle lights
- motivated off-screen source

## Roles
- key
- fill
- rim / edge
- background
- practical
- negative fill
- bounce

## Continuity
Maintain:
- source direction
- sun position
- practical state
- exposure logic
- shadow direction
- color temperature

## Avoid
"cinematic lighting" without defining actual source behavior.
