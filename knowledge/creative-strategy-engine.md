## Purpose

This module owns the upstream creative problem before production design begins:

BRIEF
→ STRATEGIC PROBLEM
→ HUMAN / CULTURAL / CATEGORY TENSION
→ INSIGHT
→ IDEA TERRITORIES
→ CONCEPT STRESS TEST
→ SELECTED CONCEPT
→ STORY / EXPERIENCE HANDOFF

It does **not** own camera, shot design, generation strategy, Veo prompting, or final-video QA.

## When to invoke

Use this module when:
- the user has a brief but no strong concept,
- the idea feels generic or interchangeable,
- multiple directions need to be explored,
- a commercial / branded / music-video concept needs a stronger human premise,
- the user asks to brainstorm, find an insight, develop a Big Idea, or critique a concept.

Skip or abbreviate it when:
- the concept is already explicitly approved,
- the user is requesting a downstream shot/prompt from an approved sequence,
- the work is purely technical execution.

## Phase 1 — Intake

Extract:
- audience,
- objective,
- message,
- desired audience response,
- mandatory elements,
- constraints,
- channel / format,
- budget or production limits when known,
- competitive/category context when relevant,
- what success means.

Do not ask generic questions if a reasonable production assumption is sufficient.

### Idea-level check

Decide the altitude of the requested idea:

- **business** — changes what the company does,
- **brand** — durable brand belief/platform,
- **tagline** — verbal compression of a brand idea,
- **advertising** — durable communication idea across executions,
- **campaign** — time-bounded expandable idea,
- **non-advertising** — activation, utility, object, experience, stunt, behavior,
- **execution** — one concrete film/post/asset/mechanic.

For film and video work, most requests land at:
`advertising`, `campaign`, or `execution`.

Do not mistake a technique for an idea.
"Use split screen" is an execution device, not automatically a concept.

## Phase 2 — Insight

Use several lenses rather than free association.

### Four-point strategy
1. Problem — what is actually blocking the audience or communication?
2. Insight — what human truth explains the problem?
3. Advantage — what can this story/product/artist uniquely exploit?
4. Strategy — what should the work make the audience think, feel, or do?

### Jobs-to-be-done lens
Ask:
"What job is the audience hiring this piece of communication or entertainment to do?"

Examples:
- reassure,
- give permission,
- validate identity,
- create status,
- release tension,
- make a difficult truth easier to face,
- make a product choice feel obvious,
- make a song's emotional thesis visible.

### Tension spotting

Look for at least one:

- **human tension** — what a person wants vs what blocks them,
- **category tension** — what the category promises vs what it usually delivers,
- **cultural tension** — what people publicly say vs what they actually do.

A useful tension contains friction.
If everything resolves cleanly before the idea starts, the concept may be decorative.

### Insight format

Prefer one sentence:

`[audience/character] wants [X], but [Y] gets in the way, because [Z human truth].`

The wording is optional; the causal logic is not.

## Phase 3 — Structured ideation

Generate genuinely different territories using methods from different families.

### Structural methods
- subtraction,
- division,
- multiplication,
- task unification,
- attribute dependency,
- SCAMPER,
- selected TRIZ contradiction thinking,
- morphological combinations.

### Association methods
- bisociation,
- forced connection,
- random entry,
- analogy,
- synectics.

### Inversion / perturbation
- reverse the expected behavior,
- worst possible idea,
- provocation ("what if the opposite were true?"),
- remove the most obvious category convention,
- swap cause and effect,
- turn limitation into mechanism.

### Default exploration rule

When exploration is actually needed:
- generate 6–12 raw directions internally,
- expect the first few to be obvious,
- preserve only the 2–4 most structurally different territories for user-facing comparison,
- do not present ten near-duplicates as "options."

Each candidate must state:
- tension,
- concept in one sentence,
- core mechanic,
- emotional register,
- why this specific project owns it,
- likely visual/sonic consequence.

## Phase 4 — Concept stress test

Do not use award-style scoring as objective truth.

Use scores only as diagnostic heuristics.

Evaluate:

### Brief fit
- Does the idea solve the stated objective?
- Does it express the intended message without explanation?
- Would the intended audience recognize the relevance?
- Are mandatory constraints respected?

### Distinctiveness
- Could a competitor or unrelated artist use the same concept unchanged?
- Is the mechanism a category cliché?
- Is the concept merely a visual style label?

### Emotional specificity
Prefer a specific compound response over generic "happy/sad/epic."

Examples:
- bittersweet relief,
- embarrassed affection,
- restless hope,
- vulnerable defiance,
- dry resentment,
- euphoric exhaustion.

### Simplicity
Can the idea be explained in one sentence without losing the core?

### Executability
Can it become actual scenes and shots?
Can the available generation method reproduce its critical mechanism?

### Scalability
If the brief needs a campaign/platform:
can the idea create multiple executions without repeating the same joke?

## Kill-your-darlings pass

For the current favorite, argue against it:

- Why is it generic?
- What would make it embarrassing?
- What is the first thing an audience might misunderstand?
- Which part exists only because it sounds clever in a treatment?
- What production dependency could kill it?
- What stronger, simpler version exists?

If the counterargument is stronger than the concept, do not defend the concept.
Replace it.

## Anti-cliché test

Name the obvious version of the brief first.

Then ban it unless the concept intentionally subverts it.

Examples:
- inspirational montage,
- generic slow-motion hero walk,
- neon city with no narrative reason,
- emotional single tear,
- product floating in black space,
- "ordinary life but cinematic",
- split screen with no meaningful temporal/spatial rule.

A familiar device is allowed when its rule creates new meaning.

## Recursion rule

If the leading concept is weak:

1. identify the weakest dimension,
2. change the thinking method,
3. reconsider the insight if necessary,
4. generate a structurally different alternative,
5. run the stress test again.

Do not endlessly polish wording around a weak mechanism.

Plateau behavior:
if two passes only produce cosmetic changes, restart from tension/insight rather than continuing downstream.

## Optional case calibration

The original smixs skill includes a large historical campaign library and pattern taxonomy.
Use that library as optional external calibration when advertising originality materially matters.

Do not load hundreds of campaign cards into normal film/video context by default.

If using external cases:
- use them to identify saturated mechanisms and structural analogues,
- do not treat awards as proof that a new idea is good,
- distinguish inspiration from copying,
- preserve source attribution.

## Handoff contract

The selected concept handed to the production-director pipeline must contain:

- **one-sentence concept**
- **strategic/human tension**
- **audience understanding goal**
- **audience feeling goal**
- **memorable residue**
- **core mechanism**
- **storytelling mode**
- **visual consequences**
- **sound consequences**
- **forbidden clichés**
- **production risk**
- **why this project specifically owns the idea**

Then continue into:
STORY / EXPERIENCE
→ VISUAL LANGUAGE
→ CHARACTER / WORLD
→ SEQUENCE DESIGN
→ SHOT DESIGN.
