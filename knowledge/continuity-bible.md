# Continuity Bible

## Track continuity in five domains

### Character
- face
- hair
- wardrobe
- makeup
- injuries
- wetness
- dirt
- emotional state

### Prop
- ownership
- hand
- position
- orientation
- damage state

### Spatial
- actor position
- screen direction
- eyeline
- camera side
- location geometry

### Temporal
- time of day
- elapsed time
- weather progression
- lighting progression

### Narrative
- what audience knows
- what each character knows
- unresolved setup
- completed actions

## Rule
End state of shot N should become valid start state for shot N+1 unless a time or space transition is explicit.
