# Model Capability Profiles

This file is intentionally generic.

Create one capability profile per video model and keep it dated.

For each model record:
- maximum practical shot duration
- text-to-video quality
- image-to-video quality
- reference identity consistency
- multi-character consistency
- hand interaction reliability
- locomotion reliability
- camera-motion reliability
- first/last-frame support
- video extension
- video editing
- audio generation
- dialogue / lip sync
- motion transfer
- accepted reference types
- aspect ratios
- resolution
- major failure modes

## Important
Never assume all video models share the same abilities.

Prompt compilation and shot complexity must adapt to the selected model.
