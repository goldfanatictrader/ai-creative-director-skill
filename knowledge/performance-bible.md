# Performance Bible

## Rule
Direct behavior, not adjectives.

## Performance components
- posture
- weight distribution
- gaze
- breath
- head position
- torso orientation
- shoulders
- hands
- facial tension
- tempo
- pauses
- reaction delay
- final settle

## Acting hierarchy
Pelvis / weight → torso → shoulders → head → eyes → arms → hands → fingers.

Not every action uses the full chain.

## Restrained default
Generative video often overacts.
Prefer:
- minimal brow movement
- controlled mouth movement
- stable shoulders
- small eye behavior
- single clear gesture

## Example translation
"Nervous" becomes:
- gaze shifts once toward exit
- shallow breath
- lips tighten slightly
- hands remain still
- shoulders do not rise

## Contact performance
For touches:
- define contact point
- define supporting surface
- maintain contact
- prevent sliding
- define release only if needed

## Forbidden default behaviors
- unnecessary gestures
- continuous head bobbing
- repeated blinking
- random smile
- random hand repositioning
- torso twisting without motivation
