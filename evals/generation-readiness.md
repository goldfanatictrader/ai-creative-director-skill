# Eval — Generation Readiness

READY only when all applicable items pass:

- creative purpose clear
- story context clear
- character reference resolved
- wardrobe resolved
- location resolved
- start state defined
- observable action defined
- final state defined
- performance constraints defined
- camera specified
- motion specified
- lighting specified
- continuity validated
- complexity acceptable
- target model selected
- generation mode selected
- relevant negative constraints selected

Otherwise:
NOT READY FOR GENERATION
