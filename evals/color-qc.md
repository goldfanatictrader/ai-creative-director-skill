# Color Grading QC Checklist

## Source
- [ ] source color space identified
- [ ] transfer function identified
- [ ] no accidental double transform
- [ ] RAW interpretation checked
- [ ] AI source classified as scene/display-referred where possible

## Match
- [ ] exposure continuity
- [ ] white-balance continuity
- [ ] skin continuity
- [ ] black-level continuity
- [ ] highlight continuity
- [ ] saturation continuity
- [ ] practical-light continuity
- [ ] time-of-day continuity

## Temporal
- [ ] no exposure pumping
- [ ] no skin hue flicker
- [ ] no wardrobe hue mutation
- [ ] no background palette drift
- [ ] no highlight flicker
- [ ] no temporal denoise artifacts

## Creative
- [ ] look supports story
- [ ] color script preserved
- [ ] key subject remains visually prioritized
- [ ] skin remains believable
- [ ] product/brand color remains accurate
- [ ] grade is consistent across representative scenes

## Output
- [ ] correct output transform
- [ ] correct gamut
- [ ] correct transfer function
- [ ] SDR reviewed
- [ ] HDR reviewed if applicable
- [ ] graphics reviewed
- [ ] subtitles reviewed
- [ ] compressed delivery reviewed

## Final
- [ ] scopes checked
- [ ] reference monitor checked
- [ ] consumer-device sanity check
- [ ] no clipping/banding/chroma breakup beyond creative intent
- [ ] approved stills / reference frames archived
