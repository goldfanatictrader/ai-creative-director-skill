# Eval — Audience Perception Simulator

Domain: what an audience actually perceives, as distinct from what the creator knows they meant. The single biggest self-deception in creative work is mistaking "I know what this means" for "a stranger would get it from the footage alone." Run this pass reading ONLY the shot list / sequence — never the treatment or brief — to simulate a first-time viewer.

## 1. Blind Read Test
Read through the shot sequence (start/end states, actions, dialogue if any) as if seeing it for the first time, with no access to the concept/treatment document. Answer:
- What do I think is happening?
- What do I think the character wants/feels?
- What do I think this is trying to sell/say/make me feel?
Compare against the actual intent (`storytelling-bible.md` §7 emotional arc, `creative-direction.md` intent triad). Gaps here mean the sequence isn't carrying its own meaning — it's relying on the treatment to explain itself, which the real audience never sees.

## 2. Visual Clarity Test (dialogue/subtitle off)
Conceptually mute all dialogue and remove all subtitles/text. Ask: is the story still legible from blocking, action, composition, and expression alone? If not, identify exactly which beat depends on words to be understood, and either accept that as a deliberate choice (some things are fine to only land via dialogue) or redesign that beat to carry visually.

## 3. Sound-Off Test (for social/commercial specifically)
A large share of social-platform viewers watch muted by default. Ask: does the video still communicate its core message and hook with audio off? Check specifically: is meaning carried by on-screen text/captions/visual action, or does it collapse without narration/music?

## 4. First-Frame / Hook Intelligence (commercial & social)
- **First frame**: does it work as a still image? Would it stop a scroll?
- **First 1 second**: is there movement/change that rewards continued attention?
- **First 3 seconds**: has the core premise/curiosity-gap been established? (Most platforms report this as the primary drop-off window.)
- **Retention hook**: what specific reason does the viewer have to keep watching past the hook — a question raised, a promise made, a pattern that invites completion?
Not every format needs this (a narrative short earns attention differently than a TikTok ad) — apply per `knowledge/video-taxonomy.md` family/platform classification.

## 5. Verdict format
```
blind_read: [what a first-time viewer would conclude]
intended: [what was actually meant]
gap: none | minor | major
visual_clarity_without_dialogue: PASS | FAIL — [which beat fails, if any]
sound_off_viability: PASS | FAIL | N/A (not social/commercial)
hook_strength: [1-3 second assessment, if applicable]
```

## 6. Rule
This is a perception check, not a taste check — it doesn't ask "is this good," it asks "does this communicate what it's supposed to." A technically beautiful sequence that fails the blind read is not ready; a rough sequence that passes it communicates the right thing and can be polished.
